HDRcade Python Helper — Save Index (.json)

Purpose: scan your save’s map/ folder using native filesystem traversal (fast), output a compact pz_map_index.json, then load it in the web tool’s Index / Fast Mode.

Why: browser folder scans can freeze on very large servers (hundreds of thousands / millions of bin files).

What the index enables

  • Instant bin availability (no browser scan)
  • Safehouse overlay + hover owner names
  • Auto-protect safehouse cells (KEEP)
  • Safehouse proximity heatmap + legend
  • Unsafe delete blocking
