HDRcade Python Helper — Save Index (.json)

Purpose: scan your save’s map/ folder using native filesystem traversal (fast), output a save_index.json, then load it in the web tool’s Index / Fast Mode.

Why: browser folder scans can freeze on very large servers (hundreds of thousands / millions of bin files).

Safe: the helper does not delete anything. It only reads files and writes a JSON index.

Download HDRcade PZ helper.zip

Files (in this zip)

  • helper/hdrcade_pz_b42_save_indexer.py — main script
  • helper/run_helper_windows.bat — Windows wrapper
  • helper/run_helper_linux.sh — Linux wrapper
  • helper/SAVE_INDEX_SCHEMA_v1.json — JSON schema reference

How to use

Windows

  1. Open the helper/ folder.
  2. Double-click run_helper_windows.bat.
  3. Paste your SAVE ROOT path (the folder that contains map\).
  4. It creates helper/save_index.json.

Linux

  1. Open a terminal in the helper/ folder.
  2. Run: chmod +x run_helper_linux.sh
  3. Run: ./run_helper_linux.sh
  4. It creates helper/save_index.json.

Load the index in the web tool

  1. Open index.html
  2. Go to Index / Fast Mode → Load Save Index (.json)
  3. Select helper/save_index.json

What the index enables

  • Instant bin availability (no browser scan)
  • Safehouse overlay + hover owner names (best-effort extraction)
  • Auto-protect safehouse cells (KEEP)
  • Safehouse proximity heatmap + legend
  • Unsafe delete blocking
