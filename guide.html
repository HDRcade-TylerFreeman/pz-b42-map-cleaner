HDRcade PZ B42 Map Cleaner (42.13+) — Guide

This tool deletes only map bin files: map/<binX>/<binY>.bin

Safe workflow

  1. Stop your server
  2. Back up the save folder
  3. Load the save folder (the folder containing map/)
  4. Draw rectangles / or set Keep Cells
  5. Use Dry-run heatmap to review
  6. Export a script and run it from the save root
  7. Restart server

Basemap

Put map.jpg next to index.html.

  • On GitHub Pages, file names are case-sensitive: it must be exactly map.jpg.
  • Corner lock TR/BL is ON by default and assumes HDRcade’s map extents.

Terminology

  • Tile: world coordinate (what b42map shows)
  • Bin: 8×8 tiles stored as one .bin
  • Cell: 300×300 tiles
