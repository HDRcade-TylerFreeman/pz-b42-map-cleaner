HDRcade PZ B42 Map Cleaner (42.13+) — Guide

What this tool deletes

Only map bin files: map/<binX>/<binY>.bin (each bin = 8×8 tiles)

Safe workflow

  1. Stop the server
  2. Back up the save folder
  3. Load your save folder (or load a Save Index .json)
  4. Use KEEP Cells / presets / safehouse protection to protect bases and towns
  5. Use dry-run heatmap to review
  6. Export a delete script and run it from your save root (where map/ exists)
  7. Restart server

Fast Mode (recommended for big servers)

If your save has hundreds of thousands of bin files, scanning in the browser can be slow or unstable. Use the Python helper to generate a Save Index (.json), then load it in the tool.

GitHub Pages basemap gotcha

GitHub Pages is case-sensitive. Your basemap must be named exactly map.jpg and be in the same folder as index.html.

Terminology

  • Tile: world coordinate (what b42map shows)
  • Bin: 8×8 tiles stored as a .bin file
  • Cell: 300×300 tiles (useful for keeping regions)
