HDRcade PZ B42 Map Cleaner (42.13+) — Guide

Written for tired admins at 3am: simple, safe, and blunt.

What this tool does

Project Zomboid stores the world in small map files called bins (files ending in .bin).

When you delete a bin file, the game will regenerate that area the next time someone visits it.

Safe workflow (do this every time)

  1. Stop the server
  2. Back up the save folder (copy the entire save somewhere safe)
  3. Load the save folder (the folder containing map/)
  4. Use Keep Cells to protect towns/bases
  5. Check Dry-run heatmap (green kept, red would delete)
  6. Export a script (.bat/.sh) or delete directly
  7. Restart the server

Terms (simple)

Tile — a single coordinate in the world (what b42map shows).

Bin — a file covering 8×8 tiles. Stored as map/<binX>/<binY>.bin.

Cell — a larger grid area of 300×300 tiles. Great for “keep these towns”.

Keep Cells — list the cells to keep, then delete everything else.

Where to run exported scripts

The script must be run from your Save root directory — the folder that contains map/.

The exported scripts refuse to run if map/ is missing. This prevents “ran it in the wrong folder” disasters.

Safehouses (auto-protect)

The tool can attempt to read players.db and detect safehouse regions. This is best-effort because schemas vary.

Always double-check visually using the heatmap.

Common mistakes

  • Deleting map files while the server is running
  • Running scripts from the wrong folder (not the save root)
  • Not checking the heatmap before deleting
  • Forgetting to protect bases / towns / safehouses
