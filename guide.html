HDRcade PZ B42 Map Cleaner (42.13+) — Guide

This tool helps you delete map/ coordinate .bin files in a controlled way.

Quick start

  1. Put your map.jpg next to index.html.
  2. Run the helper in helper/ to generate save_index.json.
  3. Open index.html using localhost (recommended) or GitHub Pages.
  4. Click Load save_index.json.
  5. Use Shift + Drag to add KEEP boxes.
  6. Click Apply inverse selection then Export delete script.

Selection controls

  • Drag = pan
  • Wheel = zoom
  • Shift + Drag = add KEEP box
  • Ctrl + Shift + Drag = subtract KEEP box
  • Right-click inside a KEEP box = remove that box
  • Backspace/Delete = undo last KEEP box

Safehouses

Safehouses are extracted from map_meta.bin by the helper and drawn as green dashed rectangles.

Safehouse padding expands protection by N tiles. Default is 0. Padding is shown as lighter green dashed outline.

Safety

  • Export is blocked if your delete plan overlaps a protected safehouse area.
  • The script checks that you run it from a folder containing map/ before deleting anything.
  • Always back up your save first.

GitHub Pages note

Browsers can’t scan your filesystem on GitHub Pages. Use Fast Mode with the helper.
